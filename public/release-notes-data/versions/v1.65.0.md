### Runtime behavior changes

#### Plan behavior
- `genesyscloud_group` — refresh populates optional `include_owners` (defaults to `true` when omitted).
- `genesyscloud_knowledge_document_variation` — refresh now writes `ordered_type` and `unordered_type` for list block properties into state when the API returns them.
- `genesyscloud_organization_authentication_settings` — refresh populates `timeout_settings` from the API even when the block is omitted from configuration.
- `genesyscloud_organization_presence_definition` — `language_labels` map keys are no longer validated at plan time; `OnQueue`, `Offline`, and `Idle` are accepted for `system_presence`.
- `genesyscloud_outbound_messagingcampaign` — exactly one of `email_config` or `sms_config` must be set; `sms_config` validation runs only when that block is present; `email_config` is read into state on refresh.
- `genesyscloud_quality_forms_evaluation` — refresh populates computed `context_id` and `published_id`; `published` is no longer synced from the API on normal read and is only set during bulk export.
- `genesyscloud_task_management_workitem_schema` — refresh populates computed `version`.
- `genesyscloud_webdeployments_configuration` — `messenger.styles.primary_color` is validated as a hexadecimal color; `cobrowse.pause_criteria.condition` diffs ignore case for operator values.

#### Apply behavior
- `genesyscloud_group` — create and update send `include_owners` to the API.
- `genesyscloud_knowledge_document_variation` — publish and delete failures now report the underlying API error instead of a misleading unrelated error.
- `genesyscloud_outbound_messagingcampaign` — create and update send `email_config` to the API; `sms_config` is validated only when configured.
- `genesyscloud_quality_forms_evaluation` — publishing on create or update stores the published form ID in `published_id` and changes the Terraform resource ID to the new draft form ID returned after publish.

#### Export behavior
- `genesyscloud_architect_ivr` — exported block labels use the IVR name only.
- `genesyscloud_flow_loglevel` — bulk export is now supported.
- `genesyscloud_knowledge_knowledgebase` — export pagination stops when the API returns a repeated page token, avoiding incomplete or looping enumeration.
- `genesyscloud_outbound_messagingcampaign` — `email_config.reply_to_address.route_id` and `email_config.reply_to_address.domain_id` are resolved to routing email references; `email_config.from_address` route and domain IDs are no longer resolved to references.
- `genesyscloud_quality_forms_evaluation` — `published` is set from published-version lookup during export.
- `genesyscloud_responsemanagement_response` — exported block labels prefix the response name with its library name(s).
- `genesyscloud_routing_queue` — `outbound_messaging_sms_address_id` is no longer resolved to `genesyscloud_routing_sms_address` references.
- `genesyscloud_task_management_worktype` — export always sets `disable_default_status_creation = true`.
- Bulk export label sanitization — duplicate exported block labels receive hash suffixes based on the label plus occurrence count (for example, `foobar3` for the third duplicate), which can change resource block names when names collide.

### Upgrade impact
- `genesyscloud_integration_action_draft` is newly available for managing draft integration actions.
- `genesyscloud_group` adds optional `include_owners` (defaults to `true`); existing configurations are likely unaffected.
- `genesyscloud_outbound_messagingcampaign` now requires exactly one of `email_config` or `sms_config`; email campaigns are fully supported. Review campaigns that previously omitted both blocks or relied on email settings that were ignored.
- `genesyscloud_quality_forms_evaluation` changes how publishing affects Terraform state: after publish, the resource ID becomes the new draft ID and `published_id` holds the published version. Refresh `published` expectations if you relied on it being synced on every read.
- `genesyscloud_organization_presence_definition` accepts additional `system_presence` values and no longer validates `language_labels` map keys at plan time.
- `genesyscloud_webdeployments_configuration` adds push-notification label keys and stricter messenger color validation.
- Bulk export block labels may change for IVRs, response management responses, and other resources with duplicate names; routing queue exports no longer resolve SMS address IDs.
- Bulk export now supports `genesyscloud_flow_loglevel`.
- Most other existing configurations are likely unaffected.
