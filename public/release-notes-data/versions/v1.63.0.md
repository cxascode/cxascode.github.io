### Runtime behavior changes

#### Plan behavior
- `genesyscloud_knowledge_document` — `published` is optional, computed, and deprecated; refresh no longer syncs it from the API, and documents are read in draft state when `published` is false.
- `genesyscloud_routing_queue` — `users` is no longer computed, so omitting it avoids API-populated member lists in state and reduces plan diffs when members are managed outside Terraform.
- `genesyscloud_routing_queue` — new optional `last_agent_routing_mode` accepts `Disabled`, `QueueMembersOnly`, or `AnyAgent`.
- `genesyscloud_outbound_campaign` — `dynamic_contact_queueing_settings.sort` is optional and computed; changing `sort` or `filter` forces replacement with a new campaign ID.
- `genesyscloud_oauth_client` — computed `client_id` and `client_secret` placeholders appear in state for referencing from integration credentials.
- `genesyscloud_task_management_worktype_status` — `category` no longer accepts `Unknown`; transition-related attributes are deprecated and computed.

#### Apply behavior
- `genesyscloud_architect_ivr` — create and update retry transient HTTP 400 responses before failing.
- `genesyscloud_knowledge_document` — create no longer publishes documents through `published`; update sets `published` to `false` after apply.
- `genesyscloud_integration_credential` — for `pureCloudOAuthClient` credentials without `clientSecret` in `fields`, the provider attempts to populate the secret from a matching OAuth client or provider metadata cache.
- `genesyscloud_oauth_client` — when `directory_client_secret` is set, the client secret is written to a file on create; linked integration credential create/update writes `client_id` to state and clears `client_secret` from state.
- `genesyscloud_routing_queue` — `last_agent_routing_mode` is sent on create and update; member ring number updates retry transient HTTP 404 responses before failing.
- `genesyscloud_task_management_worktype` — `disable_default_status_creation` is applied on create.

### Upgrade impact
- Two new resources are available: `genesyscloud_conversations_messaging_integrations_whatsapp` for WhatsApp messaging integrations and `genesyscloud_task_management_worktype_status_transition` for worktype status transition rules.
- `genesyscloud_knowledge_document` no longer publishes documents through the `published` attribute; create variations with `genesyscloud_knowledge_document_variation` instead. Existing configurations that set `published = true` should be reviewed after upgrade.
- Status transition settings on `genesyscloud_task_management_worktype_status` are deprecated; migrate `destination_status_ids`, `default_destination_status_id`, `status_transition_delay_seconds`, and `status_transition_time` to `genesyscloud_task_management_worktype_status_transition`.
- `genesyscloud_routing_queue` `users` is no longer populated from the API when omitted; existing stacks that relied on computed queue members may need explicit `users` configuration or should omit the attribute intentionally.
- `genesyscloud_oauth_client` adds placeholder attributes and optional secret file output to simplify linking OAuth clients with `genesyscloud_integration_credential` resources.
- `genesyscloud_outbound_campaign` dynamic contact queueing settings gain a `filter` attribute and relaxed `sort` requirements; changing `sort` or `filter` replaces the campaign.
- `genesyscloud_recording_media_retention_policy` supports optional `team_ids` conditions across policy types.
- The `genesyscloud_task_management_worktype_status` data source ID format changed; update any references that assume the old ID shape.
- Bulk export may produce different Terraform block labels for flows, integrations, knowledge documents, users, and other resources when names collide; bulk export for `genesyscloud_outbound_contact_list` contacts waits longer with exponential backoff before retrieving signed export URLs.
- Most other existing configurations are likely unaffected.
