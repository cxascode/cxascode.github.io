### Runtime behavior changes

#### Plan behavior
- `genesyscloud_guide` — `status`, `latest_saved_version`, and `latest_production_ready_version` are optional in configuration while remaining computed from the API.
- `genesyscloud_guide` — read refreshes the Terraform resource ID from the API, which can surface during plan refresh.
- `genesyscloud_webdeployments_configuration` — `journey_events.tracking_settings.excluded_query_parameters`, `should_keep_url_fragment`, and `search_query_parameters` are deprecated and have no effect.
- `genesyscloud_flow` — flow lookup by name now includes flows with virtual agent enabled in addition to standard flows.
- `genesyscloud_routing_wrapupcode` — lookup failures now surface the API error message in retry and non-retryable diagnostics instead of a separate generic not-found retry message.
- Shared retry helpers — a broader set of timeout conditions (including `context deadline exceeded`) trigger automatic retries during read and plan operations.

#### Apply behavior
- `genesyscloud_auth_role` — create and update no longer fail when a configured permission policy cannot be validated; a warning is logged instead.
- `genesyscloud_task_management_worktype` — updates to `default_expiration_seconds` now send the configured value to the API; create and update retry automatically on HTTP 409 conflict responses.
- `genesyscloud_task_management_worktype_status` — create, update, and delete retry automatically on HTTP 409 conflict responses.
- `genesyscloud_task_management_worktype_status_transition` — update retries automatically on HTTP 409 conflict responses.
- Shared retry helpers — a broader set of timeout conditions trigger automatic retries during create, update, and delete operations.

#### Export behavior
- `genesyscloud_integration` — bulk export resolves `createTimeOffRequests`, `timeOffBalances`, `timeOffTypes`, `updateTimeOffRequests`, and `userAccountIds` in `config.properties` as `genesyscloud_flow` references.
- `genesyscloud_location` — bulk export writes `Default PCV Location` as a data source block instead of a managed resource.
- `genesyscloud_routing_utilization_label` — bulk export writes `System Default Label` as a data source block instead of a managed resource.
- `genesyscloud_telephony_providers_edges_phone` — bulk export omits `line_base_settings_id` from exported configuration.
- `genesyscloud_telephony_providers_edges_trunkbasesettings` — bulk export resolves `site_id` as a `genesyscloud_telephony_providers_edges_site` reference and excludes autogenerated EDGE trunk base settings from the resource list.
- `genesyscloud_architect_flow` — flow enumeration for export now includes flows with virtual agent enabled in addition to standard flows.
- `genesyscloud_integration_credential` — credential enumeration during export uses cursor-based paging instead of page-number paging.

### Upgrade impact
- `genesyscloud_integration_webhook` is newly available for reading webhook integration IDs and invocation URLs by integration name.
- `genesyscloud_auth_role` create and update is more permissive when permission policies cannot be validated; review roles that previously failed at apply time because of missing product entitlements.
- `genesyscloud_task_management_worktype` updates to `default_expiration_seconds` now take effect correctly; re-apply if you relied on that attribute.
- Task management worktype, status, and status transition resources retry HTTP 409 responses, which can reduce transient apply failures under concurrent API use.
- `genesyscloud_flow` data source lookups may return flows that were previously omitted when virtual agent is enabled.
- Deprecated `journey_events.tracking_settings` attributes on `genesyscloud_webdeployments_configuration` have no effect; remove them when convenient to avoid future removal warnings.
- Bulk export output changes for integrations (flow references), locations, utilization labels, phones, trunk base settings, and architect flows; re-exported configurations may differ.
- Shared retry helpers retry a broader set of timeout conditions across resources that use them.
- Most other existing configurations are likely unaffected.
