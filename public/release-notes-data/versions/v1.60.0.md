### Runtime behavior changes

#### Plan behavior
- `genesyscloud_group` — refresh populates the new `calls_enabled` value from the API.
- `genesyscloud_routing_queue` — refresh maps `media_settings_message` using message-specific fields, which can surface `sub_type_settings` and service-level values that were previously omitted or flattened incorrectly.
- `genesyscloud_routing_email_route` — read retries when the API returns an empty route list or when the route is not found in its domain, instead of clearing the resource from state.

#### Apply behavior
- `genesyscloud_group` — create and update send `calls_enabled` to the Genesys Cloud API.
- Provider token pool — plan and apply operations that cannot obtain a pooled OAuth client within `token_acquire_timeout` fail with a timeout error instead of blocking indefinitely.
- Provider token pool — provider startup fails if the token pool cannot be initialized within `token_init_timeout`.

#### Export behavior
- `genesyscloud_integration_credential` — exported Terraform block labels now use `Integration-{integration_name}` instead of `{integration_name}_{credential_name}`.
- `genesyscloud_integration_action` — export preserves zero-value entries in `config_response.translation_map_defaults`.
- Bulk export — concurrent resource enumeration is limited to the configured `token_pool_size`, which can change timing and throughput for large exports.

### Provider configuration changes
- `token_acquire_timeout` — optional duration for waiting on an available OAuth client from the token pool (default `5m`).
- `token_init_timeout` — optional duration for initializing the token pool at provider startup (default `10m`).
- `sdk_client_pool_debug` — optional boolean that enables debug logging for token pool operations.

### Upgrade impact
- `genesyscloud_group` gains the optional `calls_enabled` argument (default `true`). Existing group configurations should continue to work without changes.
- `genesyscloud_routing_queue` resources that use `media_settings_message` may show plan diffs after upgrade because state is mapped more accurately to the API.
- `genesyscloud_routing_email_route` refresh is more robust when the API returns empty or missing route lists; resources are no longer silently dropped from state when a route is temporarily unavailable.
- Exporting `genesyscloud_integration_credential` resources now generates different Terraform block labels; update references if you rely on the previous naming pattern.
- Large exports may run with different concurrency because enumeration is capped by `token_pool_size`.
- Plan and apply operations that exhaust the token pool may now fail with a timeout after `token_acquire_timeout` instead of blocking indefinitely.
