### Upgrade impact
- Existing configurations are likely unaffected unless you use removed journey outcome resources, deprecated Web Chat media types, or the new optional attributes listed above.
- Remove `genesyscloud_journey_outcome` resources and data sources from configuration before upgrading; the resource type is no longer available in this provider version.
- Journey action maps must drop outcome-based trigger blocks and any `webchat` media types; update templates similarly.
- Upgrading migrates `genesyscloud_routing_queue` (`members`, `wrapup_codes`) and `genesyscloud_team` (`member_ids`) state from sets to lists automatically; review plans if you rely on set ordering semantics.
- Decision table resources can move from nested `rows` to `rows_csv_filepath`; nested `rows` remains supported but is deprecated.
- Function data actions need a local zip at export-provided paths and benefit from `function_config.file_content_hash` for reliable change detection.
- Outbound campaign rules with `campaign_rule_processing = "v2"` can adopt date/time and runtime/wait-time condition blocks; legacy `campaign_rule_conditions` cannot use those v2-only types.
- Dictionary feedback resources using the default Genesys engine still require at least three `example_phrases`; the extended engine uses `display_as` instead.
