### Runtime behavior changes

#### Plan behavior
- `genesyscloud_flow` — `file_content_hash` is optional in configuration and computed from `filepath`, including `s3://` paths, during plan diff evaluation.
- `genesyscloud_guide` — read refreshes `status` and `source` from the API and sets `latest_saved_version` and `latest_production_ready_version` to null when the API returns no version, which can surface during plan refresh.

#### Apply behavior
- `genesyscloud_flow` — `filepath` values can use `s3://` URIs; the provider computes and stores `file_content_hash` after a successful apply and warns when `file_content_hash` remains in configuration.
- `genesyscloud_guide` — create runs a content-generation job when `source` is `Prompt` and always creates an initial guide version.
- `genesyscloud_guide_version` — create updates the latest saved version instead of failing when the API returns HTTP 409 because the latest version is not Production Ready.

#### Export behavior
- `genesyscloud_flow` — bulk export omits `file_content_hash` from exported `.tf` configuration while writing the computed hash to exported state.

### Upgrade impact
- `genesyscloud_flow` configurations can drop the required `file_content_hash` argument; the provider computes it from `filepath`. Remove `file_content_hash` from `.tf` files when you see the deprecation warning, and expect bulk-exported flow blocks to omit that attribute.
- `genesyscloud_flow` `filepath` values can use `s3://` URIs where local or HTTP(S) paths were previously required.
- `genesyscloud_guide` supports `prompt` and `url` for Prompt-sourced guides and always creates an initial guide version on create; review create logic if you manage guides outside Terraform.
- `genesyscloud_guide_version` create is more tolerant when a non–Production Ready version already exists; existing version resources are likely unaffected.
- `genesyscloud_flow` data source lookups wait longer before failing when a flow is not immediately found.
- Most other existing configurations are likely unaffected.
