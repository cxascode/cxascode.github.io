### Runtime behavior changes

#### Plan behavior
- `genesyscloud_guide` — refresh no longer populates `status`, `source`, `latest_saved_version`, or `latest_production_ready_version`; plans may show these values removed from state after upgrade.
- `genesyscloud_guide_version` — refresh no longer populates `state`; plans may show `state` removed from state after upgrade.

#### Apply behavior
- `genesyscloud_guide` — create always sets source to Manual and no longer reads `source`, `prompt`, or `url` from configuration.
- `genesyscloud_guide` — create no longer runs prompt-based content generation or automatically creates an initial guide version; manage content with `genesyscloud_guide_version` separately.
- `genesyscloud_guide_version` — create always attempts to publish the version to ProductionReady; draft-only creation via `state = "Draft"` is no longer supported.
- `genesyscloud_guide_version` — when the parent guide already has a production-ready version, update creates a new version instead of patching the existing one; otherwise it updates the latest saved version.
- `genesyscloud_guide_version` — update always attempts to publish the version to ProductionReady.
- `genesyscloud_guide_version` — when create fails because the latest version is not production-ready, the provider retries by updating the existing version instead of requiring a 409 response.

#### Export behavior
- `genesyscloud_guide` — exported configuration includes only `name`; `source`, `prompt`, and `url` are no longer written to generated Terraform.
- `genesyscloud_guide_version` — export includes only each guide's latest saved version (no longer exports a separate production-ready version when it differs).
- `genesyscloud_guide_version` — export resolves `resources.data_action.data_action_id` references to `genesyscloud_integration_action` resources.
- `genesyscloud_guide_version` — export omits `generate_content` from generated configuration.

### Upgrade impact
- Remove `source`, `prompt`, `url`, `status`, `latest_saved_version`, and `latest_production_ready_version` from `genesyscloud_guide` configurations; plans will fail if these arguments remain.
- Remove `state` from `genesyscloud_guide_version` configurations; create and update now always publish to ProductionReady.
- Existing `genesyscloud_guide` resources that relied on Prompt-based generation or automatic initial version creation need to be reworked: create the guide with only `name`, then manage content with `genesyscloud_guide_version`.
- `genesyscloud_guide_version` updates on guides that already have a production-ready version may create a new version and change the resource ID; review plans carefully before apply.
- Export output for guides and guide versions may differ: simpler guide blocks, fewer versions per guide, integration action references resolved, and `generate_content` omitted.
