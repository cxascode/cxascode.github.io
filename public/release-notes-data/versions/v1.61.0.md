### Runtime behavior changes

#### Plan behavior
- `genesyscloud_flow` — the data source emits a warning when `type` is omitted, noting that it will become required in a future release.
- `genesyscloud_flow` — when multiple flows share the same name, the data source uses `type` to select the matching flow; if multiple matches exist and none match the requested type, lookup fails with an error.
- `genesyscloud_routing_queue` — `canned_response_library_mode` is populated from the API during refresh when not set in configuration.
- `genesyscloud_routing_queue` — `media_settings_callback.mode` is no longer auto-populated from the API; omitting it in configuration may produce plan diffs where a value was previously computed.
- `genesyscloud_routing_queue` — state is automatically migrated from schema version 1 to version 2, removing deprecated auto-dial fields from non-callback media settings in stored state.
- `genesyscloud_responsemanagement_response` — `library_ids` is stored and compared as a set rather than an ordered list, which can change plan output when list order previously differed from API order.
- `genesyscloud_telephony_providers_edges_phonebasesettings` — refresh reads and writes `line_base.station_persistent_webrtc_enabled` from line base properties.
- `genesyscloud_telephony_providers_edges_site` — state is automatically migrated from schema version 1 to version 2, removing `outbound_routes` from stored state.
- `genesyscloud_outbound_contact_list_contact` — read no longer runs post-read state consistency validation, which may change plan output for existing resources.

#### Apply behavior
- `genesyscloud_telephony_providers_edges_site` — create, read, and update no longer manage inline `outbound_routes`; outbound routes must be managed with `genesyscloud_telephony_providers_edges_site_outbound_route` resources.
- `genesyscloud_telephony_providers_edges_site_outbound_route` — create, read, update, and delete succeed without setting `ENABLE_STANDALONE_OUTBOUND_ROUTES`.
- `genesyscloud_telephony_providers_edges_phonebasesettings` — create and update send `line_base.station_persistent_webrtc_enabled` to the Genesys Cloud API.

#### Export behavior
- `genesyscloud_flow` — flow enumeration during export now paginates through all results instead of stopping after the first page, so large organizations export the full flow inventory.
- `genesyscloud_organization_authentication_settings` — export preserves zero values for `timeout_settings.idle_token_timeout_seconds`.
- `genesyscloud_telephony_providers_edges_site_outbound_route` — export runs without requiring `ENABLE_STANDALONE_OUTBOUND_ROUTES`.
- `genesyscloud_user` — bulk export skips users that lack an ID or email address.

### Upgrade impact
- `genesyscloud_telephony_providers_edges_site` no longer supports inline `outbound_routes`. Move outbound route configuration to `genesyscloud_telephony_providers_edges_site_outbound_route` resources. Existing state is migrated automatically, but HCL that still sets `outbound_routes` on a site must be updated.
- `genesyscloud_telephony_providers_edges_site_outbound_route` works without setting `ENABLE_STANDALONE_OUTBOUND_ROUTES`. Remove that environment variable from CI, export jobs, and local workflows if you added it solely for this resource.
- `genesyscloud_routing_queue` removes auto-dial and auto-end arguments from non-callback media settings blocks. Configurations that set `auto_end_delay_seconds`, `auto_dial_delay_seconds`, or `enable_auto_dial_and_end` under `media_settings_chat`, `media_settings_message`, or `media_settings_email` must drop those arguments. Callback settings under `media_settings_callback` still support the auto-dial fields. State is migrated to schema version 2 automatically; plan diffs are possible where removed arguments were previously in state.
- `genesyscloud_responsemanagement_response` configurations must treat `library_ids` as a set rather than an ordered list.
- `genesyscloud_flow` data source lookups should include `type` to avoid warnings and to disambiguate flows with duplicate names.
- Exporting `genesyscloud_organization_authentication_settings` now preserves zero values for `timeout_settings.idle_token_timeout_seconds`.
- Bulk export skips `genesyscloud_user` entries that lack an ID or email address.
