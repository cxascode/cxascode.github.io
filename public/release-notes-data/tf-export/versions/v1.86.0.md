### Resource attributes changed

- `enable_dependency_resolution` — Description updated to document that dependency resolution adds a `depends_on` attribute to both `genesyscloud_flow` and `genesyscloud_script` resources, and that referenced dependencies inside flow or script configuration are resolved and exported.

### Resource behavior

None detected.

### Export behavior

- When `enable_dependency_resolution` is enabled, the exporter checks that the Architect dependency tracking index is operational before resolving flow dependencies. If the index is not ready, it triggers a rebuild and waits (up to approximately five minutes) before continuing.
- Dependency resolution processes resources in a stable order sorted by resource ID, so `depends_on` attribute ordering is consistent across repeated export runs.
- When `ignore_cyclic_deps` is enabled, bidirectional cyclic dependencies are automatically removed from generated `depends_on` attributes to reduce Terraform cycle errors during apply.

### Related export output changes

- Data source `genesyscloud_script` resources (referenced but not managed) are skipped during dependency resolution, matching existing behavior for data source flows.
- Exported `genesyscloud_knowledge_document` resources are more likely to resolve `label_names` to `genesyscloud_knowledge_label` Terraform references when the label exporter was not already loaded during the export run.

### Upgrade impact

- Existing `genesyscloud_tf_export` configurations are likely unaffected unless you use `enable_dependency_resolution` or `ignore_cyclic_deps`.
- Exports with dependency resolution enabled may take longer on the first run when the Architect dependency tracking index needs to be rebuilt.
- Re-exporting with dependency resolution may produce differently ordered but more consistent `depends_on` values.
- Exports that reference scripts as data sources will no longer pull in dependencies for those scripts.
- Knowledge document exports may produce additional `genesyscloud_knowledge_label` references where label resolution previously fell back to plain names.
