### Export behavior

- Default resource block label sanitization now transliterates non-Latin characters to ASCII. This behavior was previously available only when the optional time-optimized sanitizer (`GENESYS_SANITIZER_TIME_OPTIMIZED`) was enabled; that separate sanitizer path is removed and all standard exports use the unified default sanitizer.
- When tf-export auto-resolves duplicate Terraform block labels, the disambiguation hash suffix changes from a numeric FNV-based value to a hexadecimal SHA-256-based value (first 10 characters).
- When multiple resources sanitize to the same block label, the second occurrence receives one `_<hash>` suffix, the third receives two `_<hash>` suffixes, and so on.
- When tf-export resolves `depends_on` references, dependencies on data sources now include the required `data.` prefix (for example, `data.genesyscloud_<type>.<label>` instead of `genesyscloud_<type>.<label>`).
- When exporting more than one output format in a single run (for example, HCL and JSON together), diagnostics from each export step are now collected and returned together instead of only the last step's result being reported.

### Related export output changes

- Exported resource block labels may differ for resources with non-Latin names because transliteration now runs in the default sanitizer.
- Exported resource block labels for duplicate-name edge cases may differ from v1.63.0 output because of the new hash format and occurrence-based suffix logic.
- Exported `depends_on` values that reference data sources may differ from v1.63.0 output because the `data.` prefix is now included where it was previously omitted.

### Upgrade impact

Existing `genesyscloud_tf_export` configurations are unaffected. Re-exports may produce different resource block labels for non-Latin names and for duplicate-label disambiguation. Re-exported configuration that includes `depends_on` references to data sources may show corrected `data.`-prefixed references. Multi-format export runs may surface additional or combined error messages when more than one export step fails.
