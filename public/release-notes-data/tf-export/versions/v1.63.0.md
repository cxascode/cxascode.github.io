### Export behavior

- When tf-export auto-resolves duplicate Terraform block labels for the same resource type, the appended suffix changes from `_<numeric_hash>` to `_BRCM<numeric_hash>`. Exported resource block names in this edge case will differ from v1.62.0 output.
- Resource block label sanitization now returns an empty label when a resource name is empty or sanitizes to no valid characters, instead of failing during label processing. This applies to both the default sanitizer and the time-optimized sanitizer (`GENESYS_SANITIZER_TIME_OPTIMIZED`).

### Related export output changes

- Exported resource block labels may be empty when a resource name is empty or sanitizes to no valid characters, instead of the export failing during label processing.

### Upgrade impact

Existing `genesyscloud_tf_export` configurations are unaffected. Most exports are unchanged. Re-exports that previously produced auto-disambiguated block labels may generate different resource block names because of the new `_BRCM` suffix format. Exports that include resources with empty or fully stripped names are less likely to fail and may instead emit empty block labels.
